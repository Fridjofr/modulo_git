ZIMONS - Pacote jogável

Como testar:
1. Extraia este ZIP.
2. Abra o arquivo index.html no Chrome ou Edge.
3. Jogue o fluxo: criação -> mapa -> falar com Lira -> escolher Zimon -> voltar ao mapa -> apertar T para transformar -> falar com Lira de novo -> batalha.

Controles:
- WASD / setas: mover
- E: interagir
- T: transformar / voltar ao humano (depois de escolher o starter)

Importar no Codex:
1. Crie um projeto novo no Codex.
2. Envie o ZIP ou a pasta extraída.
3. Abra o projeto e peça para o Codex rodar/editar o index.html.
4. Se quiser subir para um repositório, mantenha a pasta assets junto do index.html.

Estrutura:
- index.html: jogo principal
- assets/: imagens e sprite sheets
- sprites_meta.json: metadados dos recortes de sprites
